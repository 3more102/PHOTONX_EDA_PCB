# Evidence model

SourceRef identifies where an object came from. Evidence records why an inference was made and its confidence. Inferred component identity must never be presented as confirmed without source evidence.

For composed manufacturing geometry, provenance is **component-local and order-aware**. Dark operations contribute only material that they actually added to the image and that survives later clear operations. Clear operations contribute only boundary they actually created by erasing existing material and that remains on the final component boundary. Redundant dark operations, clear-before-dark no-ops, duplicate clears, erased dark material, and point-only clear contact do not create provenance dependencies. Stable IDs for composed components follow the same effective-contribution rule so no-op or fully erased operations cannot rename an otherwise unchanged component.

Curved Gerber flashes used by LPC image composition carry `gerber_flash_polygonization` evidence on each final component they actually influence. The evidence records the original C/O shape, deterministic inscribed-chord method, curved segment count, and maximum chord-error target. Non-orthogonal R/O D03 flashes are materialized as CopperRegion polygons and carry the same evidence kind with effective output rotation, aperture dimensions, approximation state, and method; rotated rectangles are polygon-exact while rotated obround curved boundaries retain the 0.005 mm chord-error target.
Linear D01 aperture sweeps carry `gerber_track_polygonization` evidence. Circular tracks record capsule construction; rectangular tracks record exact convex sweep materialization; obround tracks record convex sweep plus deterministic inscribed-chord curved boundaries. The evidence records aperture shape, centerline length, aperture dimensions, effective output rotation, curved segment count, approximation state, and maximum chord-error target. Rectangular sweeps remain polygon-exact at arbitrary finite LR; C/O curved boundaries use the 0.005 mm chord-error policy.
Standard C/R/O D03 flashes with a centered round-hole modifier carry `gerber_aperture_hole` evidence. It records outer shape/dimensions, hole diameter, effective output rotation, curved-segment counts, chord-error bound, approximation state, and `hole_semantics=transparent`. The transparent hole is part of the operation geometry and is never rewritten as an independent clear operation.
Standard P D03 flashes carry `gerber_polygon_flash` evidence recording vertex count, outer diameter, template rotation, LM mirror state, effective object rotation, optional hole diameter, hole tessellation count, error bound, and approximation state. The regular-polygon outer boundary is exact; only an optional round-hole boundary is chord-error-bounded. Solid P D01 sweeps carry `gerber_polygon_track` evidence with the same template/transform state plus centerline length and `method=convex_sweep_exact`; these sweeps are polygon-exact.
A supported single Code-5 polygon aperture macro is reduced to the same standard P representation before object creation. Its resulting D03/D01 objects therefore use the same `gerber_polygon_flash` / `gerber_polygon_track` evidence and transform semantics rather than introducing a parallel macro-only geometry model.
When a G02/G03 circular-aperture arc track participates in LPC composition, its original `gerber_arc_tessellation` evidence is retained and `gerber_track_polygonization` additionally records the 0.005 mm centerline chord target plus a conservative combined boundary-error budget of <=0.010 mm after capsule-cap polygonization.
