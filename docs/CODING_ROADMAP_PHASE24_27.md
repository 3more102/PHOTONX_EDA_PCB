# PHOTONX EDA PCB — Phase 24–27 Roadmap

Phase 24 expands the synthetic/reference regression corpus and dataset manifests.
Phase 25 adds measured performance, memory, spatial candidate indexing and incremental recomputation.
Phase 26 audits architectural overlap and introduces compatibility bridges rather than breaking public APIs.
Phase 27 defines Development, Research, Review and Manufacturing-export-candidate release profiles.

A manufacturing-export-candidate gate is a software/evidence readiness state. It is not electrical certification or manufacturer approval.
