# Standards and format references

The implementation should be checked against primary format documentation:

- Ucamco Gerber downloads and current specification: https://www.ucamco.com/en/guest/downloads/gerber-format
- Ucamco Gerber reference site: https://www.ucamco.com/en/gerber
- KiCad board file format: https://dev-docs.kicad.org/en/file-formats/sexpr-pcb/
- KiCad S-expression conventions: https://dev-docs.kicad.org/en/file-formats/sexpr-intro/index.html

As of 2026, Ucamco publishes a 2026.05 Gerber Layer Format specification and test files. PHOTONX should use that corpus for future conformance work.
