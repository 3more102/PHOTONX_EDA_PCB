# PHOTONX EDA PCB — Phase 40–43

Phase 40 promotes conservative Excellon G85 canned-slot evidence into the production parser.
Phase 41 carries slots through BoardModel, JSON/project bundles and object indexing.
Phase 42 integrates slot geometry into mechanical-copper DRC with plating-aware severity.
Phase 43 extends executable parser conformance and capability reporting.

This is deliberately limited support. G00/G01/G02/G03 routed Excellon geometry remains unsupported and is never approximated as a slot.
