# Production Release Profiles

Profiles:
- Development: permissive engineering iteration.
- Research: green tests, deterministic output and moderate evidence thresholds.
- Review: adds zero critical unsupported syntax, review closure and round-trip requirements.
- Manufacturing-export candidate: strict provenance/completeness, closed review, ground-truth and round-trip gates.

Passing these gates does not prove the PCB is electrically safe or manufacturable.
