# PHOTONX EDA PCB — Phase 28–31

Phase 28 integrates spatial candidate indexing into the real connectivity and DRC paths while retaining brute-force reference implementations for parity testing.

Phase 29 adds parser conformance cases for the explicitly supported Gerber/Excellon subsets and expected strict/permissive behavior.

Phase 30 adds deterministic synthetic stress boards and benchmark workloads. Timing measurements are evidence, not fixed CI promises.

Phase 31 adds production-board validation/admission and explicit migration plans for overlapping validation/reporting APIs.

The goal is deeper correctness, scale, and release evidence rather than simply increasing module count.
